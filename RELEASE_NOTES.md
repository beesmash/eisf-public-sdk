# Release Notes

## v0.1.0

Initial developer release of EISf Public SDK.

- Python reference implementation
- TypeScript reference package
- canonical JSON Schema
- provider-neutral adapter interface
- OpenAI Responses adapter
- generic Responses-compatible adapter
- Ollama/local adapter
- `eisf analyze`, `eisf validate`, `eisf dev`, and `eisf conformance`
- v0.1 conformance fixtures
- GitHub CI and release workflows

The release intentionally excludes proprietary JANUS, KRONOS, JANUS FORGE, private scoring, private routing, prompts, datasets, and client-specific methods.
