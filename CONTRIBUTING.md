# Contributing

Thank you for contributing to the EISf Public SDK.

1. Preserve the five canonical semantic stages.
2. Keep the public core provider-neutral.
3. Do not submit confidential Beesmash, client, employer, or third-party material.
4. Do not attempt to reverse engineer or reconstruct private JANUS/KRONOS methods.
5. Add tests for behavioral changes.
6. Keep compatibility claims precise.

Pull requests should explain the problem, proposed change, tests, and any compatibility effect.

By contributing, you represent that you have the right to submit the contribution under the repository license.
