# Release Checklist

Before publishing a release:

- [ ] public/private boundary reviewed
- [ ] no credentials, private prompts, client data, or proprietary datasets
- [ ] Python unit tests pass
- [ ] EISf Conformance Suite passes 8/8
- [ ] TypeScript build and tests pass
- [ ] example case validates
- [ ] version numbers agree
- [ ] CITATION.cff version/date checked
- [ ] release notes checked
- [ ] license/notice present
- [ ] tag follows semantic versioning
- [ ] GitHub Actions green
