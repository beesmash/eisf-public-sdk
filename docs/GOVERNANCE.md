# Public Canon Governance

The public canon is intentionally small.

The five stages — Event, Impact, Scenario, Adaptation, Decision — are the core interoperability contract.

PATCH releases clarify without changing required meaning. MINOR releases may add backward-compatible optional capabilities. MAJOR releases may change canonical requirements.

Normative semantic changes should include a rationale, compatibility impact, schema changes when applicable, updated conformance fixtures, and migration guidance.

Public governance does not require publication of proprietary Beesmash implementation details.
