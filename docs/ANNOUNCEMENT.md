# Public Announcement Draft

Hello, world.

I am releasing the first public implementation of EISf:

**Event → Impact → Scenario → Adaptation → Decision**

EISf is a provider-neutral framework for structured human and AI reasoning, decision support, and software-development workflows.

The EISf Public Canon and EISf Public SDK are available openly for developers, researchers, organizations, educators, and anyone who wants to build with them.

The public release includes Python and TypeScript reference implementations, OpenAI/Responses-compatible and Ollama/local adapters, a JSON schema, CLI tools, and a public conformance suite.

This public release intentionally does not disclose proprietary JANUS EISf, KRONOS, JANUS FORGE, private model routing, private scoring, private prompts, private datasets, or client methods.
