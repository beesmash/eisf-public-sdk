# Changelog

All notable public changes to the EISf Public SDK are documented here.

## [0.1.0] — 2026-10-08

Initial public SDK release candidate.

### Added

- EISf Public Canon: Event → Impact → Scenario → Adaptation → Decision
- Python reference SDK and `eisf` CLI
- TypeScript reference package
- canonical JSON Schema
- OpenAI Responses adapter
- generic Responses-compatible adapter
- Ollama/local adapter
- `eisf analyze`, `eisf validate`, `eisf dev`, and `eisf conformance`
- eight-fixture EISf Conformance Suite v0.1
- external-driver conformance protocol
- GitHub CI across Python 3.10–3.13 and TypeScript
- automated GitHub release packaging
- citation, governance, security, trademark, and public/private-boundary documentation

### Compatibility claim

A third-party implementation that passes every mandatory fixture may state:

> **EISf Core Compatible — Self-Tested against EISf Conformance Suite v0.1**

This is a self-test interoperability claim, not independent certification or a claim of equivalence with proprietary Beesmash/JANUS systems.
